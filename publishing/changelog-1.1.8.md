# MobLog 1.1.8

- Record successful mining and herbalism gathers as small world map and minimap markers. Merge nearby recordings of the same resource.
- Switch nearby minimap icons to hollow rings when the corresponding WoW tracking mode is active. Show tooltips on both maps and provide separate visibility options.
- Link observed gathering loot to individual gathering locations. **Gathering sources** in the Item catalog shows the node name, area, approximate coordinates, and recorded quantity. Select a source to set a waypoint on supported maps.
- Show successful gathers and the recorded quantity of each item in the gathering location tooltip. Previously saved markers gain item quantities as you gather there again.
