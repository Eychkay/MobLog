# MobLog 1.1.8 — Gathering locations

Mine ore or gather herbs to mark the location on your world map and minimap. Hover over a marker to see the most recent gather, approximate coordinates, and how many items MobLog recorded there. With the matching WoW tracking mode active, nearby minimap markers use hollow rings so live tracking dots can show through.

Open **Items → Item catalog → Gathering sources** to see where an item appeared in your gathering loot. Choose a location to set a waypoint on a supported map. Existing markers keep their gather counts and gain item quantities from newly recorded gatherings.

- **Retail:** Extract `MobLog` and `MobLog_TrinityDB` from `MobLog-1.1.8.zip`.
- **Forever:** Extract `MobLog` and `MobLog_ForeverDB` from `MobLog-1.1.8-Forever.zip`.

Install both folders into the matching client's `Interface/AddOns` directory. Restart WoW to load the new files. Existing records and preferences are retained.
