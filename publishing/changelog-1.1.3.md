# MobLog 1.1.3 — Forever Release

- Added support for World of Warcraft: Forever 1.60.1.
- Added a dedicated Forever catalog with 4,864 NPCs, 1,229 items and 2,197 possible drop relationships.
- Added Forever map locations, area filtering and capital-city detection.
- Automatically select the correct catalog for each client.
- Show difficulty and item IDs to distinguish same-name loot variants.

Install **MobLog** and **MobLog_ForeverDB** from **MobLog-1.1.3-Forever.zip**, then restart the game.

Dungeon and raid records remain loot-based. Missing creature details are recovered after leaving the instance when the client makes them available. Catalog coverage is incomplete; unknown details may require a personal encounter. No other addon is required.
