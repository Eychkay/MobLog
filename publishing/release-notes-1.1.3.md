# MobLog 1.1.3 — Now available for Forever

Build your account-wide bestiary in **World of Warcraft: Forever**. Track encounters, kill records, personal loot percentages, collection ranks and discovery locations, with interactive creature models and a separate Forever catalog.

This release adds Forever support, appropriate map and capital-city handling, and clearer labels for loot variants with the same name.

**Installation:** Extract **MobLog** and **MobLog_ForeverDB** into `_forever_/Interface/AddOns`, then restart WoW. Use `/moblog` or `/ml` to open the addon. Select the **Forever / 1.60.1** game version when downloading.

Inside dungeons and raids, creatures are recorded only through looting. Missing details are recovered outside instances when available. Catalog coverage and automatic tracking remain subject to the data exposed by the game.
