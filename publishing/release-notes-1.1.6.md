# MobLog 1.1.6 — Personal notes and map pins

Save reminders inside creature entries or on the world map. Shift + right-click the map to add a note at your cursor, then optionally use the dropdown to link a creature by name or NPC ID. Linked pins also appear under **Details & Places** in the creature entry. Right-click a pin to edit it.

- **Retail / Midnight:** Extract both folders from `MobLog-1.1.6.zip`.
- **Forever:** Extract both folders from `MobLog-1.1.6-Forever.zip`.

Install into the matching client's `Interface/AddOns` folder and restart WoW so it loads the new files. Existing records and preferences are retained.
