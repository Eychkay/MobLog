# MobLog 1.1.6

- Add personal notes to a specific NPC variant from the list or album, including undiscovered catalog entries.
- Create a map note at the cursor with Shift + right-click on the world map, with optional NPC linking via a searchable dropdown.
- Edit or unlink existing pins, remove them with Shift + right-click, or open the linked bestiary entry with left-click.
- Display map notes above the map art with compact markers that stay the same size as you zoom.
