# MobLog 1.1.7

- Add **My inventory** under **Items**. Search the recorded holdings of your characters by name or item ID and filter by owner or item type.
- Record bags, equipped items, and personal and shared bank contents. Show quantities by character and storage location with the last scan time. Retail and Forever keep separate records.
- Show gold, silver, and copper in the inventory toolbar. Click the balance for the breakdown by character and shared bank.
- Link inventory entries to their drop sources and the item catalog back to recorded holdings. Offer an optional inventory count on item tooltips.
- Use scrollable item and storage lists. Keep WoW item quality colors on a darker item list, and refresh item tooltips after scrolling or loading item data. Fall back to the item ID if a stored link fails.
- Use native WoW dropdowns for sorting, filters, and linked creatures in map notes. Keep the segmented location navigation.
