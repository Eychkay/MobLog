# MobLog 1.1.4 — Bestiary Album

- Added an optional parchment-style album alongside the existing mob list.
- Added a double-page creature view with an interactive 3D model, Details & Places, Loot and Characters.
- Added album filters for Hostile, Non-hostile, Undiscovered and Unknown attitude, plus All entries. Combine them with search, area, type and collection rank filters.
- Undiscovered album cards display known creature names; entries without a name retain their NPC ID.
- Added collection progress, discovery dates and NEW markers to album cards.
- Added Previous and Next navigation through the filtered album and history-aware return navigation.
- Simplified the list to Details & Places and a More details button that opens the creature's double-page view.
- Enlarged the list model preview and the double-page model area, tightened the book header and increased its default zoom. Reset uses the new book zoom.
- Corrected dragon-frame sizing and alignment on album portraits.
- Saved the preferred List/Album mode and album category; returning restores filters, selection and page or scroll position.

**Retail / Midnight:** install `MobLog-1.1.4.zip` containing `MobLog` and `MobLog_TrinityDB`.

**Forever:** install `MobLog-1.1.4-Forever.zip` containing `MobLog` and `MobLog_ForeverDB`.

Existing personal records are preserved. No additional addon is required. Dungeon and raid tracking remains loot-based; catalog information never counts as a personal discovery or kill.
